# Privacy Policy

CobViz is designed with **Privacy-by-Design** as a core principle.

## Data Processing
- **Source Code**: All parsing and analysis happen within your infrastructure. CobViz does not transmit source code to external servers by default.
- **AI Integration**: When using Local Providers (e.g., Ollama), intelligence is processed entirely on-premises. When using Cloud Providers, users are responsible for the provider's privacy terms.
- **Telemetry**: CobViz contains **no telemetry** or tracking code.

## Privacy Considerations (GDPR/POPIA)
- CobViz processes legacy source code which may contain metadata. We recommend using the built-in **Data Redactor** for all external AI interactions.
